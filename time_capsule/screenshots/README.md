## Tipps für gute Screenshots

1. Verwende ein modernes Smartphone-Mockup für professionelles Aussehen
2. Stelle sicher, dass keine persönlichen Daten sichtbar sind
3. Verwende echte Beispielinhalte statt Platzhalter für authentisches Aussehen
4. Optimiere die Bildgröße (ca. 1080px Breite ist ideal für GitHub)

## Screenshot-Tools

- Für Android: Nutze die Bildschirmaufnahme-Funktion des Geräts
- Für iOS-Simulator: Cmd+S drücken
- Für Mockups: [MockUPhone](https://mockuphone.com/) oder [AppMockUp](https://app-mockup.com/)

## Größe optimieren

Vor dem Hochladen zu GitHub, optimiere die Bildgröße mit einem Tool wie:
- [TinyPNG](https://tinypng.com/) 
- [ImageOptim](https://imageoptim.com/) (Mac)
- [Squoosh](https://squoosh.app/) (Web)
